# Landing-Monitoring-Service

> Landing Monitoring Service — централизованный сервис синтетического мониторинга

---

## 🚀 Возможности

- Регулярно проверяет каждый лендинг по расписанию с разных «профилей устройств»
(эмуляция браузера, ОС, разрешения, User-Agent)
- Проверяет не только HTTP-статус, но и бизнес-критичные сценарии: загрузку ключевых
элементов, доступность формы заявки, работу CTA, отсутствие JS-ошибок, корректность
вёрстки (скриншоты + сравнение с эталоном)
- Замеряет метрики производительности (TTFB, DOMContentLoaded, LCP, полная загрузка,
размер страницы)
- Агрегирует результаты, строит дашборды и автоматически оповещает ответственных при
деградации
- Предоставляет API и интеграции для специалистов по контекстной рекламе
